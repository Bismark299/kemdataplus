POST
https://instantdatagh.com/api.php/orders
Create one or many orders for the same network. Wallet is debited once for the total.

Headers
Header	Required	Description
x-api-key	Yes	Your API key
Content-Type	Yes	application/json
JSON body
Field	Required	Description
network	Yes	MTN, AirtelTigo, or Telecel
phone_number	Yes	One phone (10 digits) or comma-separated list for bulk.
data_amount	Yes	One plan key or comma-separated keys aligned by position with phones (first phone ↔ first amount).
Example — single order
curl -X POST https://instantdatagh.com/api.php/orders \ -H "x-api-key: api_8cce8c154128a1c73aa92c14ac0d705f322dd4e38f615b40a20911283eb86f63" \ -H "Content-Type: application/json" \ -d '{"network":"MTN","phone_number":"0501234567","data_amount":"5"}'
Example — bulk (same network)
curl -X POST https://instantdatagh.com/api.php/orders \ -H "x-api-key: api_8cce8c154128a1c73aa92c14ac0d705f322dd4e38f615b40a20911283eb86f63" \ -H "Content-Type: application/json" \ -d '{"network":"MTN","phone_number":"0246995732, 0538806691, 0505265279","data_amount":"1, 2, 3"}'
Pairs: 0246995732→1, 0538806691→2, 0505265279→3 (keys must exist for that network on your account). Maximum 500 pairs per request.

Common errors
400 — mismatched list lengths, invalid phone/plan, insufficient balance, over bulk limit
401 / 403 — invalid key or blocked account
429 — rate limit exceeded
